## How I work

- **Readable code:** clear names, small methods, separate controller, service and repository layers.
- **Small, regular commits** with meaningful messages.
- **Tests** for the important behaviour of each project.
- **A README for every repository:** setup steps, endpoints, and what I learned.
- **No secrets in the repositories:** configuration is kept out of version control.
